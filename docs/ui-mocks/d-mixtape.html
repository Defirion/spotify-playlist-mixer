Design notes Direction D

Palette

#FFFDF5 paper#000000 ink#FFE14D acid #FF6B9D pink#4D7CFF blue#5CE1A8 mint #B79BFF purple#FF9F43 orange

Fonts

Space Grotesk 700, tight tracking (-.045em), uppercase headlines. Space Mono for every number and label. Permanent Marker only on the tape label.

All borders 3px #000, shadows 5px/0 blur via CSS variables; press = translate by the shadow offset.

Signature ideas

  1. The mix is a cassette: the tape window stripes re-proportion live as you drag priorities, and the reels shrink/grow with progress.
  2. Every playlist owns one colour plus a generated cover (blobs, sunburst, checker, stripes) that follows it through stickers, tape, breakdown, tags and example squares.
  3. Tracklist is a ticket stub with a dotted tear line; dragged rows lift with a bigger hard shadow. CTAs are always black with a pink offset.

Trade-off

Drama over density: chunky borders, big numerals and tilted stickers eat space, so the page is taller than a calm UI. Rows in the tracklist use dashed hairlines instead of full borders to keep the long list legible.

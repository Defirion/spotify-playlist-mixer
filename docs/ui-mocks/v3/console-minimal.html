    Design notes
    Palette
    Page #F3F4F6, panels #FFFFFF, ink #15171A, muted #5B6470, rules #D5D9DF, one accent #C8420F for the primary action only. Data colours (one per playlist): #E4572E, #1B998B, #E0A100, #5A7D2A, #A63D6B, #4F6D8F.
    Type
    IBM Plex Sans for text. IBM Plex Mono for numbers. 13px minimum.
    Ideas
    One thing on screen at a time (Blend, then Review). The fader readout is the share of the mix, so the controls and the result are the same object. Exact values, run lengths and the example order stay behind Fine tune. Search, presets and track pickers open only when asked.
    Trade-off
    Hiding the exact numbers keeps the screen calm but costs one click for anyone who wants precision.
    Tells avoided
    No color ramps, glass, glow, pills, icon tiles, side stripes, tiny labels, step numbers, fake status, or hero stats. Totals are sentences.
    Mock numbers
    Shares and totals are live arithmetic from the faders, so the default is a few songs off the spec figures.

    Design notes · Direction A “Console”

    Palette

    #E4E1DA body #D2CEC4 inset #1A1A18 ink #FF4F00 action #D8DAC2 LCD #161614 OLED #E0457B CH1 #16A08A CH2 #3D6BE0 CH3

    Fonts

    Space Grotesk for labels, names and button caps. Space Mono for every readout: LCDs, counts, durations, meters. The pairing keeps the ink-on-plastic feel with a technical edge.

    Signature ideas

    1. Priority is a real vertical fader beside a live VU meter showing the actual share of the mix; it flips between songs and minutes with the balance toggle.
    2. Orange is reserved for actions and active state only; every playlist gets its own accent that threads through strip, meter, sequencer cell and track tag.
    3. Presets are chunky EP-style pads, and the example mix is a step sequencer that re-patterns as faders move.

    Trade-off

    Drama over density. Each channel strip spends ~620px of height on faders, knobs and meters, so five or more playlists means horizontal wrapping and more scrolling than a compact list would. Tactile precision costs screen space; a 10-channel layout would need a condensed strip variant.

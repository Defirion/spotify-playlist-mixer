Design notes Direction B - Studio

Palette

#08090A canvas#131416 panel #F7F8F8 text#8A8F98 muted #FF5C57 coral#C4F142 lime#8B7CFF violet

Hairlines are rgba(255,255,255,.08). The clip colours are the only saturated colour on screen; each playlist keeps one everywhere (bar, lane, tag, meter).

Fonts

Inter for UI text; Geist Mono (JetBrains Mono fallback) for every number, time, label and key hint, so durations always align.

Signature ideas

  • Arrangement lanes. One lane per source on a shared time ruler. Runs show the real sequence, and the edge handles drag min/max live.
  • Proportion bar. One bar is 100%. Dragging a divider rebalances its two neighbours, with numeric entry underneath.
  • Crate footer. A persistent tally with a stacked source meter and a target tick, plus a Ctrl+K command menu for presets and actions.

Trade-off

Pro-tool density and vocabulary (lanes, ruler, mono readouts) in exchange for approachability. A casual user may find it more instrument than app, and on a phone the timeline becomes a horizontal scroller.
